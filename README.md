# 每日额度 PWA

一个完全本地、无账号、无后端的「每日可花额度」工具。

## 功能

- 自定义每日基础额度
- 记录消费金额和时间，显示真实负数超支
- 正余额结转和超支结转独立开关
- 撤销当天最近一笔消费
- 修改或删除历史记录，并自动重算之后的结转
- 月度额度、消费、累计余额、日均消费和超支天数
- JSON 备份导出和恢复；在 iPhone 上可通过分享菜单保存到 iCloud Drive
- 跟随系统、浅色和深色三种外观
- PWA 主屏幕安装和离线运行

金额以整数“分”保存，避免 JavaScript 浮点数造成金额误差。旧版数据会自动迁移。

## 本地运行

Service Worker 需要通过 HTTP 访问。在本目录打开 PowerShell，运行：

```powershell
python -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080`。

## 数据说明

- 设置与消费保存在当前浏览器的 `localStorage` 中。
- 清除 Safari 网站数据或卸载 PWA 会删除本地数据，请定期导出 JSON 备份。
- 结转从首次使用日期开始计算；切换结转设置或修改历史记录会重算后续日期。
